# Expense Management App (MVP)

A minimal Expense Management Single Page Application (SPA) built with Next.js (pages API routes), MongoDB, Mongoose, JWT authentication and Tailwind CSS.

## Features (MVP)
- Email/password signup & login (JWT stored in HttpOnly cookie)
- CRUD for expenses (title, amount, date) — user-specific
- React Context API global state
- Toast notifications with `react-toastify`
- Serverless-friendly MongoDB connection caching
